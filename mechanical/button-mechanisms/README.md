# Button mechanisms

Reserve left, middle and right button CAD here. Each button combines a moving
axial magnet, fixed TMAG5253 sensing and an LVCM-013-008-02 force actuator.
Define travel, mechanical stops, passive return, actuator linkage and Hall sensor
gap. Measure force/travel and cross-axis loading before tuning haptic profiles.
Keep magnetic interference and coil heating in the tolerance/calibration plan.
