# Previous electronics revisions

2026-11-05. They remain available in
[Git at the pre-cleanup revision](https://github.com/sbarisic/MagMouse/tree/f0acacb170f736648a6b5170140de5a96bac91d5).

That revision includes the original monolithic PCB, modular four-layer boards,
bench panel and fixtures, oversized two-layer variants, September quote
packages, and their generators and review images.

They describe earlier revisions; component counts, button actuators, geometry,
power paths and approval status must not be assumed to match the current boards.
Use the [active projects](../../hardware/two-layer/sandwich/README.md) for changes.

The exact September CAM submission and receipt remain under
`hardware/bench/submissions/2026-09-12-jlc-cam/`. The brake simulation retains
its original netlists under `hardware/simulation/brake/inputs/`.
